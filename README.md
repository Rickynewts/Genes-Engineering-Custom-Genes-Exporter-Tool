# 项目名称
> Genes Engineering:Custom Genes Exporter Tool
# 简介
CGET是一款基因Mod生成器，允许玩家在不编程的情况下一键导出功能，外观基因结构完整的本地XML Mod文件，允许编辑基因的加成属性，强制添加或特性，内置RGB调色板和多种实验性功能。允许上传自定义图标和封面。
简单粗暴的遍历游戏内数据并反序列化为本地XML文件。
